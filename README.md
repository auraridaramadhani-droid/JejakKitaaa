# JejakKitaaa
JejakKitaaa adalah aplikasi web interaktif untuk membantu siswa dan warga sekolah mengecek fakta, menjaga privasi digital, dan mencegah rumor atau cyberbullying sebelum share info di grup maupun medsos. Dilengkapi Cek Kilat 60 Detik, Simulasi Studi Kasus Sekolah, dan Panduan Lapor Etika yang praktis diakses lewat ponsel. Saring sebelum sharing!
